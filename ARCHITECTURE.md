# MTG Unframed — Architecture

## Technology

The application is intentionally simple.

- HTML
- CSS
- Vanilla JavaScript
- JSON
- Python for data generation
- Scryfall bulk data
- MAMP for local development
- Static hosting compatible

No JavaScript framework is currently used.

## Home view

The parameter-free route shows the home view; artist, set and About views use query parameters and browser history. The home collage randomly selects twelve distinct artworks from the curated entries in `data/home-artworks.json`, displaying four per column on larger screens and a swipeable row on mobile. Featured artworks open the existing artwork modal. Each entry contains an `illustration_id` and the corresponding `artistSlug`, which is used to fetch the existing artist shard for its image and attribution. This hand-maintained file is not generated by `tools/update_data.py`; see `tools/README.md` for maintenance and validation.

## Artist links

`data/artist-links.json` is hand-maintained and keyed by artist slug. It is not generated or overwritten by `tools/update_data.py`. At startup `loadData()` fetches it and `mergeArtistLinks()` attaches a filtered `links` object (allowed keys, `https://` only) to each matching artist. A missing or invalid file is ignored. Validate with `python3 tools/validate_links.py`.

`data/artist-artwork-aliases.json` maps names in the hand-maintained artist index to equivalent credits in generated artwork shards, retaining existing artist URLs. Missing artwork shards are reported rather than silently displayed as an empty gallery.

## Set exclusions

`data/excluded-sets.json` controls which sets are hidden from set navigation and artwork printing lists without removing their artworks from the generated data. The browser applies its explicit set-code list and optional rules at startup. See `tools/README.md` for maintenance.

The generated set index also marks sets without an artwork shard with `hasArtworks: false`. These sets are not selectable in set navigation, but their names remain in the index for reference.
